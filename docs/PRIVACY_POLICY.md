## 1. Who we are

AVA is a server-side AI shopping assistant installed by merchants on their
e-commerce stores. The merchant is the **data controller** for their
visitors; AVA is a **data processor** acting on the merchant's behalf.

Contact: **TODO — privacy@ava.example**

## 2. What we collect — the short version

- **No PII.** AVA does not collect, store, request, or process customer
  emails, names, addresses, phone numbers, payment data, or any other
  personally identifying information. The widget never asks for it and
  the server enforces this at the storage layer (anonymous identifiers
  only).
- **Anonymous fingerprints.** Each visitor gets a `visitorId` — a stable
  pseudonymous hash derived from non-identifying browser characteristics.
  It cannot be reversed to a real-world identity.
- **Behavior signals.** Page views, clicks, cart events, scroll depth,
  rage clicks, and similar interaction telemetry — none of which contain
  personal data.
- **Aggregated cart values.** For revenue attribution, we record the
  cart's USD amount at the moment an intervention fires and at the moment
  of conversion. No line-item details, no customer email.

## 3. What we collect from the merchant

When a merchant installs AVA via the Shopify App Store:

- Shopify shop domain and access token (encrypted at rest).
- Site configuration: product catalog metadata (titles, prices, IDs) used
  to power the shopping assistant.
- Webhook subscription IDs.
- Billing subscription state from Shopify's Billing API (plan, status,
  line-item IDs — see §7).

We do not request access to Shopify's **protected customer data** scope.

## 4. How we use what we collect

- Real-time detection of shopping friction (325 catalogued friction
  scenarios, F001–F325).
- Real-time intervention decisions via MSWIM scoring (intent / friction /
  clarity / receptivity / value).
- Voice-assisted shopping responses generated by Groq's Llama models.
- Aggregated analytics shown only to the merchant who owns the data.
- Billing reconciliation via the Shopify Billing API.

We do not sell visitor data, share it with advertisers, or use it for
cross-merchant profiling. Optional cross-merchant pattern contributions
are opt-in per merchant (`SiteConfig.networkOptIn`) and contain only
aggregated, pseudonymous behavior pattern frequencies.

## 5. Third-party processors

| Processor | Purpose | Region | Data shared |
|---|---|---|---|
| Shopify | Storefront integration, billing | Merchant-selected | Shop domain, anonymized event identifiers, billing state |
| Groq | LLM inference for the voice/agent path | US | Anonymized conversational context (no PII) |
| Deepgram (optional) | Voice TTS/STT | US/EU | Voice audio chunks (no PII transcripts) |
| Resend (optional, if `EMAIL_PROVIDER=resend`) | Transactional emails to merchant | US | Merchant email + digest body (no visitor PII) |
| PagerDuty (optional, if `PAGERDUTY_ROUTING_KEY` set) | Drift alerts to merchant on-call | US | Alert metadata (no visitor data) |
| Google Analytics 4 (optional, if `GA4_*` set) | Outbound event mirror | US | PII-scrubbed event metadata only |
| Mixpanel (optional, if `MIXPANEL_PROJECT_TOKEN` set) | Outbound event mirror | US/EU/IN | PII-scrubbed event metadata only |

For each optional processor:
- Configuration is opt-in by environment variable.
- A PII scrubber (`apps/server/src/exports/pii-scrubber.ts`) is applied
  before any outbound dispatch.
- URL query strings and fragments are stripped from any URL forwarded to
  third parties (a common PII leakage vector).

## 6. Data retention

- Active session telemetry: retained for **180 days** for analytics +
  model training.
- Anonymous intervention outcomes (for ML retraining): retained for
  **24 months**.
- Shopify subscription state: retained as long as the merchant has the
  app installed.
- Logs and operational metadata: **30 days**.

After retention windows expire, data is deleted by the nightly cleanup
job. Merchants can request immediate deletion at any time (see §8).

## 7. Shopify-specific compliance

Per Shopify App Store requirements, AVA implements the three mandatory
compliance webhooks:

| Topic | Behaviour |
|---|---|
| `customers/data_request` | AVA holds no customer PII; webhook is acknowledged with a record stating "no PII held". |
| `customers/redact` | No-op (nothing to redact at the customer level). Logged for audit. |
| `shop/redact` | All shop data (SiteConfig, sessions, events, evaluations, interventions, recommendations) is cascade-marked for deletion. |

Webhook implementations are HMAC-verified against `SHOPIFY_API_SECRET`
and tested at `apps/server/src/api/shopify-gdpr-webhooks.test.ts`.

## 8. Your rights (GDPR, CCPA, and equivalents)

You can:
- Request a copy of any data tied to your visitor pseudonym.
- Request deletion of all data tied to a visitor pseudonym (right to
  erasure).
- Object to processing.
- Lodge a complaint with your local supervisory authority.

Visitors should contact the merchant (the data controller) first. Direct
requests to AVA can be sent to **TODO — privacy@ava.example**; we will
forward to the appropriate merchant and respond within 30 days.

## 9. Security

- All data in transit is encrypted via TLS 1.2+.
- Database fields are encrypted at rest where the underlying provider
  supports it (SQLite dev / PostgreSQL prod).
- Shopify access tokens are stored encrypted.
- No credentials are logged.
- Access to production data is restricted to engineering staff bound by
  confidentiality.

## 10. Children

AVA is a B2B service installed by merchants and does not knowingly process
data from children under 13 (US) or 16 (EU).
